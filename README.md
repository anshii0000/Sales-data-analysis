# Sales Data Analysis Dataset

--Overview

This dataset contains historical sales transaction records from a retail business. It includes information related to customer orders, product details, sales revenue, order status, customer locations, and deal sizes. The dataset is suitable for practicing data analysis, data visualization, business intelligence, and machine learning techniques.

--Dataset Information

* **Rows:** 2,823 sales records
* **Columns:** 24 features
* **Format:** CSV

## Features Included

* Order details (Order Number, Order Date, Order Line Number)
* Product information (Product Code, Product Line, MSRP)
* Sales metrics (Quantity Ordered, Price Each, Sales Revenue)
* Customer information (Customer Name, Contact Details)
* Geographic information (City, State, Country, Territory)
* Order status and deal size classifications
* Time-based attributes (Month, Quarter, Year)

## Key Columns

| Column               | Description                                         |
| -------------------- | --------------------------------------------------- |
| ORDERNUMBER          | Unique identifier for each order                    |
| QUANTITYORDERED      | Number of units ordered                             |
| PRICEEACH            | Price per unit                                      |
| SALES                | Total sales amount                                  |
| ORDERDATE            | Date of order placement                             |
| STATUS               | Current order status                                |
| PRODUCTLINE          | Product category                                    |
| CUSTOMERNAME         | Customer name                                       |
| CITY, STATE, COUNTRY | Customer location details                           |
| DEALSIZE             | Classification of deal value (Small, Medium, Large) |

## Potential Analysis

* Sales trend analysis over time
* Revenue forecasting
* Customer segmentation
* Product performance evaluation
* Geographic sales analysis
* Deal size distribution analysis
* Business KPI dashboard creation using Power BI or Tableau

## Tools Recommended

* Python (Pandas, NumPy, Matplotlib, Seaborn)
* SQL
* Power BI
* Excel

## Objective

The primary goal of this dataset is to explore sales patterns, identify business insights, and build data-driven solutions for decision-making.
